# Salesforce Data Import Wizard — portfolio demo

An interactive demo of a product I designed and built at Salesforce.

The Data Import Wizard introduced a new pattern for importing CSV data into 
Salesforce — responsive across desktop, tablet, and mobile, with a field 
mapping interface that let users connect their data to Salesforce fields 
without technical knowledge.

## What's in this demo

- Landing page with FAQ and contextual help
- Step 1: File upload with progressive form reveal
- Step 2: Field mapping with two-tone column layout and record preview
- Step 3: Pre-import review and confirmation
- Success screen with import summary
- Import History — full Salesforce Lightning shell with a log of past imports
- Field mapping overlay with "do not import" option

## What we wanted to build next

- AI-assisted field mapping suggestions based on column names and sample data
- Duplicate detection preview before import runs
- Saved mapping templates for recurring imports
- Bulk import support beyond 50,000 records
