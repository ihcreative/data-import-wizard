About this page

The Data Import Wizard lets you import up to 50,000 records at a time using a CSV file. You can add new records, update existing ones, or do both in a single import.

To get started, you'll need a CSV file with your data. Column headers that match Salesforce field names will be mapped automatically.

For imports over 50,000 records, use Data Loader instead.

About field mapping

Your CSV columns are on the left. Salesforce fields are on the right. For your data to import correctly, each column needs to be matched to the right Salesforce field.

Mapped — the column is connected to a Salesforce field and will import.

Unmapped — no match found. That column's data will be skipped unless you map it manually.

Use Map or Change on any row to pick a different Salesforce field. You can also mark a column as "Do not import" if you want to exclude it.
